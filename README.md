# FastLesson Landing

Standalone copy of the FastClass landing page. The project contains only the
landing page, its local visual assets, and the small build/runtime helpers
needed for the static version.

## Run

```bash
npm start
```

Open `http://127.0.0.1:8080` in a browser.

To rebuild `index.html` after changing the source sections:

```bash
npm run build
```
